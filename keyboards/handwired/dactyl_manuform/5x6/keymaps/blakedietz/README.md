# Dactyl Manuform 5 x 6 keymap

## Flashing the board

1. Disconnect the side connected to USB-C
1. Disconnect the Aux coard from both halves
1. Flash the first half
1. Run `qmk flash -kb handwired/dactyl_manuform/5x6 -km blakedietz`
1. Push the button on the half that is being flashed
1. Flash the second half
1. Run `qmk flash -kb handwired/dactyl_manuform/5x6 -km blakedietz`
1. Push the button on the half that is being flashed
